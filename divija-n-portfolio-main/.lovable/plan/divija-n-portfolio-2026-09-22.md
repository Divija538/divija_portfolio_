# Divija N Portfolio

## Goal
Build a polished, recruiter-friendly, single-page engineering portfolio using only the supplied facts and content.

## Experience
- Sticky desktop navigation and an accessible mobile menu with active-section highlighting.
- Dark-first blue/indigo visual system with a working light/dark toggle and saved preference.
- Strong introduction with project, resume-placeholder, contact, and professional-profile links.
- Clearly structured About, Skills, Projects, Professional Learning, Certifications, Achievements, Education, Career Interests, and Contact sections.
- Large project showcases with abstract engineering visuals and accessible details dialogs; no invented repository or demo links.
- Validated contact form with clear success and error feedback using the visitor’s email application.
- Resume actions clearly marked as unavailable until the real resume file is supplied.

## Visual Direction
A refined engineering-console aesthetic: deep navy surfaces, crisp blue/indigo accents, restrained glass effects, compact technical labels, generous whitespace, and subtle motion. The custom abstract interface visual will suggest testing, networking, and software systems without implying a real product screenshot.

## Technical Details
- Keep the portfolio at `/` as one deliberate scrolling page, matching the requested section navigation.
- Use semantic design tokens in the global stylesheet and existing shared controls for actions and dialogs.
- Use semantic HTML, keyboard-accessible controls, visible focus states, reduced-motion support, and responsive layouts.
- Add route-specific title, description, Open Graph tags, Twitter card metadata, canonical URL, and structured data.
- Verify the main navigation, theme, mobile layout, project dialog, links, validation, and browser console in the running preview.
